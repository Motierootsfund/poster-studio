# Poster Studio — Web App Prototype

Open `index.html` in a modern browser.

Included in this first version:
- Poster templates
- Editable text
- Font size/weight/colour/alignment controls
- Background colour
- Image/logo upload
- Drag-and-drop positioning
- PNG export
- Print / PDF through the browser

Next production steps:
1. Add user accounts and cloud storage.
2. Add a larger template library.
3. Add resizeable/rotatable elements and layers.
4. Add proper high-resolution PDF export.
5. Add AI-assisted poster generation.
6. Deploy to a production hosting provider and connect a custom domain.
